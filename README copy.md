# GREEN TERMINAL Portfolio

レトロなターミナルの緑文字と、読みやすい通常のWebサイトを組み合わせた個人ポートフォリオです。HTML / CSS / JavaScriptのみで動作します。

## ファイル構成

- `index.html` — トップページ
- `projects.html` — 制作物一覧
- `project-cafeteria.html` — 食堂混雑状況確認サイトの紹介
- `project-task-calendar.html` — 課題カレンダーアプリの紹介
- `about.html` — プロフィール
- `devlog.html` — 開発ログ
- `contact.html` — 公開プロフィールへのリンク
- `style.css` — デザインとレスポンシブ対応
- `script.js` — モバイルメニューとフッターの年表示

## 公開前に必ず編集するところ

1. `YOUR_HANDLE` と `@YOUR_HANDLE` を自分のハンドルネームに置き換える。
2. `about.html` の自己紹介を自分の言葉に直す。
3. 制作物の説明を実際に実装した内容に合わせる。
4. `contact.html` にGitHubプロフィールなどの実際のURLを追加する。
5. 公開できない個人情報、秘密鍵、トークンなどが含まれていないことを確認する。
6. スマートフォンでも表示を確認する。

このテンプレートの作品画像風UIはCSSで描画したモックアップです。実際のアプリ画面が用意できたら、スクリーンショットに置き換えると、より説得力のあるポートフォリオになります。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成する。例：`portfolio`
2. このフォルダ内のファイルをリポジトリのルートにアップロードする。
3. リポジトリの **Settings → Pages** を開く。
4. **Build and deployment** の **Source** を `Deploy from a branch` にする。
5. Branchで `main`、フォルダで `/(root)` を選んで `Save`。
6. 公開完了後に表示されるURLを開く。プロジェクトサイトのURLは通常 `https://<GitHubユーザー名>.github.io/portfolio/` です。

公開には数分かかる場合があります。GitHub Pagesで公開した内容はインターネット上から閲覧可能になるため、公開前にリポジトリ内のファイルを確認してください。
