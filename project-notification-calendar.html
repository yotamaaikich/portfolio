PROJECT / 002 — WINDOWS & ANDROID APP

通知カレンダー
Windows・Androidアプリ.

Teamsやスマートフォンに届く通知を予定候補に変換し、WindowsとAndroidで共有する個人制作アプリです。

JavaScript / Node.jsKotlinFirebase

01 / OVERVIEW

通知を予定候補に変える

Windowsに届くTeams・Chrome通知や、Android端末に届くアプリ通知から課題の期限や予定を読み取り、カレンダー候補を作ります。予定は月間カレンダーと一覧で確認でき、必要に応じて内容や日付を編集できます。

02 / WORKFLOW

受信から端末間の同期まで

  • 通知アクセスを許可した端末でTeamsなどの通知を受信
  • 通知文からタイトルや日付を読み取り、予定候補を作成
  • 候補を確認・編集して、カレンダーに登録
  • Firebase Authenticationでログインし、予定をPCとAndroidで同期

03 / PRIVACY

同期するのは登録済みの予定だけ

通知の原文は端末内で処理し、クラウドへ送信しません。クラウドに同期するのは登録した予定の日付・タイトル・元アプリです。同期にはFirebaseのメールアドレスとパスワードでログインします。

04 / ENVIRONMENT

動作環境と制限

Windows版はWindows 10 version 2004以降とNode.js 20以降、Android版はAndroid 8以降が対象です。OSが通知として受け取り、通知アクセスを許可したアプリが取得できる内容を処理します。端末の電源が切れている間の通知や、過去のTeamsチャンネル履歴を取得する機能はありません。
