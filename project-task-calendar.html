01 / OVERVIEW

概要

課題や提出期限を日付ごとに管理することを目的にしたFlutterアプリです。カレンダーと日ごとのタスク表示を中心に、使いやすい課題管理画面を目指しています。

02 / IMPLEMENTATION

取り組んだこと

  • Flutter / Dartでの画面構成
  • カレンダーの日付選択と課題一覧の管理
  • ローカル保存など、データを保持する仕組みの検討
  • 課題情報の入力・整理をしやすくするUIの設計
