PROJECT / 002 — MOBILE APPLICATION

課題カレンダー
アプリ.

課題を日付ごとに整理し、提出予定を見渡せるようにすることを目指して、2026年8月にFlutter / Dartで制作した個人開発アプリです。

FlutterDartMobile UI

01 / APP FLOW

PDFから課題登録まで.

PDFを選ぶとAIが課題の内容を読み取り、確認してからカレンダーへ登録できます。

01

PDFを選択

ホーム画面から課題のPDFを選びます。

02

PDFファイルを選ぶ

ファイルピッカーから読み込むPDFを指定。

03

AIが内容を解析

Node.js経由でGeminiにPDFを送信します。

04

読み取り結果を確認

AIが抽出した課題の情報を確認します。

05

カレンダーに登録

内容を確定すると、課題が登録されます。

06

カレンダーで確認

登録した課題を日付から見つけられます。

07

締切前に通知

設定したリマインダーで締切をお知らせ。

08

通知などを設定

通知やカレンダー連携を調整できます。

アプリの機能と画面構成をもとにしたSVGイメージです。実際のアプリ画面のスクリーンショットではありません。

概要

2026年8月に個人開発した、課題を日付ごとに整理するFlutterアプリです。カレンダーで予定を見渡し、課題を管理することを目指して制作しました。

03 / IMPLEMENTATION

実装内容

  • Flutter / Dartを使った画面づくり
