PROJECT / 004 — WEB PORTFOLIO

ポートフォリオ

授業や個人開発で制作した作品と、活動の記録を紹介するためのWebサイトです。

HTMLCSSJavaScriptGitHub Pages

01 / OVERVIEW

作品を伝える場所

授業や個人開発で制作したものを、制作の背景やプロフィールとあわせて見られるようにまとめています。作品や情報をページごとに整理しました。

02 / DESIGN & FEATURES

設計と工夫

  • 緑を基調にしたターミナル風のデザインで、ページ全体の印象を統一
  • HOMEのターミナル欄にコマンドを入力すると、作品やプロフィールの位置へ移動
  • スマートフォンでも見やすいように、ナビゲーションやカード配置を調整
  • GitHub ActionsでGitHub Pagesへ自動デプロイ
  • 初回起動とページ移動に、Windows風の画面演出を追加

03 / PROCESS

制作の進め方

まず紹介する作品や活動を整理し、一覧から各作品の詳細へ移動できる構成にしました。HTML / CSS / JavaScriptで制作し、Codexも補助として活用しています。ブラウザーで表示や動作を確認し、気づいた点を修正してからGitHubへ反映し、GitHub Pagesで公開しています。
