01 / OVERVIEW

作品を伝える場所

授業や個人開発で作ったものを見やすくまとめ、制作の背景やプロフィールと一緒に伝えることを目指しました。各ページを自分で更新しながら、GitHub Pagesで公開しています。

02 / DESIGN & FEATURES

設計と工夫

  • 緑を基調にしたターミナル風のデザインで、ページ全体の印象を統一
  • HOMEのターミナル欄にコマンドを入力すると、作品やプロフィールの位置へ移動
  • スマートフォンでも見やすいように、ナビゲーションやカード配置を調整
  • GitHub ActionsからGitHub Pagesへ自動デプロイ
  • 今回、初回訪問時にレトロなWindows起動画面風アニメーションを追加

03 / PROCESS & IDEAS

制作の背景と工夫

授業や個人開発で作ったものを一か所にまとめ、初めて訪れた人にも作品や活動が伝わることを目指して制作しました。ターミナル風の世界観を全ページでそろえながら、内容を探しやすく、スマートフォンでも読みやすい構成にしています。Codexも制作補助に使い、表示を確認して気づいた点を直しながら仕上げています。

  • 作品ごとに紹介ページを作り、概要・使用技術・制作時の工夫を掲載
  • HTML / CSS / JavaScriptで、ターミナル風の画面や操作演出を制作
  • 画面幅に応じてレイアウトを調整し、スマートフォンにも対応
  • GitHubでソースを管理し、GitHub Pagesで公開・更新
