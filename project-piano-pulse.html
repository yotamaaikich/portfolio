WEB RHYTHM GAME

PIANO PULSE
8キーのリズムゲーム.

キーボードの8キーで演奏するブラウザーリズムゲーム。長押し・同時押し・HARD限定FLOAT（フロート）に対応し、オンラインランキングも備えています。

JavaScriptCanvasSupabase
ゲームで遊ぶ ↗GitHub ↗

01 / OVERVIEW

ピアノ鍵盤を使った8レーンの演奏

奥から手前へ流れるノーツを、A S D F / J K L ; の8キーで演奏するリズムゲームです。ピアノ鍵盤風の配置と、左右の手を色で区別したレーンで演奏します。

02 / FEATURES

演奏して記録を比べる

  • 35曲を収録。EASY / NORMAL / HARDの3難易度
  • 単押し・長押し・同時押し、HARD限定の黄緑色FLOAT（フロート）ノーツ
  • 難易度別チュートリアル。HARDのFLOAT練習もオン・オフ可能
  • 譜面だけの全画面表示と、スコア・コンボ・達成率の表示
  • 曲・難易度別のオンラインランキング

03 / CONTROLS

キーだけで練習からプレイまで

Enterで開始、Escで一時停止。HARDのFLOATは黄緑色の上向き矢印と帯で表示し、レーンキーを押したままSpace。Spaceを押し続けて帯に沿って別のレーンキーへ移動し、帯が終わったらSpaceを離します。区間外で押し続けるとコンボが切れます。キー配置・ノーツ速度・判定タイミング・動画の音量を変更できます。

04 / IMPLEMENTATION

ブラウザー描画とクラウドの記録

Canvasでレーンとノーツを描画しています。SupabaseのEdge Functionsでプレイ入力を再判定し、オンラインランキングへスコアを保存します。音楽はYouTubeの公式動画を埋め込み再生し、動画の読み込み待ちでは譜面を停止します。

譜面は独自の8鍵向け簡略アレンジです。原曲・映像の権利は各権利者に帰属します。YouTubeの広告が入る場合があります。
