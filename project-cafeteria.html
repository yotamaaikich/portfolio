01 / OVERVIEW

概要

食堂の混雑状況を利用者が確認できるようにすることを目指したWebアプリです。表示画面とデータベースを接続し、取得した情報を画面に反映する仕組みを作りました。

02 / IMPLEMENTATION

取り組んだこと

  • 混雑状況を表示するWeb画面の作成
  • Supabaseを使ったデータ取得と画面更新
  • データベースの接続・ポリシー・Realtime設定の確認
  • 接続エラーやデータが表示されない問題の切り分け

03 / LEARNINGS

学んだこと・改善点

フロントエンドの表示だけでなく、データベースの設定や通信状態まで確認する必要があると学びました。今後は、実際の画面キャプチャ、データ更新の仕様、テスト結果を追加して説明を具体化します。
